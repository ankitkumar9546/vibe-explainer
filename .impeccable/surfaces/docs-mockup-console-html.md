Scope: console mockup (single static HTML), mode Operate. Audience: new developers and students using AI coding agents. Task: understand what the agent did in a session. Content is sample data, labelled as such. Round 1 (Flight Recorder, grey paper) was REJECTED by the user on 2026-11-19 as plain and too grey; he asked for bold and colourful.

## Direction contract

THESIS: The console is a friendly learning app, not a log viewer: every idea sits on its own big rounded card in plain language, like a lesson app a student already opens daily. It refuses the grey instrument panel and the dark dev dashboard.

OWN-WORLD: Warm peach ground #FFF1E6, white cards with 22px radii, deep plum ink #2A1B3D. One saturated violet #6B3BFF appears only on things you can press (active tab, buttons, links, the strip handle). Each channel owns a soft fill: Soch sky, Padha mint, Badla sunflower, Chalaya coral-peach. Claims: mint = backed, sunflower = can't verify, red pill = no evidence. Baloo 2 headings, Nunito body, JetBrains Mono for code only.

STORY: The learner sees what the AI is doing, sees which claim had no proof, reads the change in plain words, then takes the quiz.

FIRST VIEWPORT: Header with mark, live pill, language and level toggles. A timeline card with chunky coloured pills per channel and a violet draggable handle. Left: prompt cards. Main: the turn title in big Baloo, claim cards in a row, tab bar, then the active tab's cards. On mobile the tab bar is a persistent bottom bar.

FORM: Warm consumer app surface (catalog challenger digital-design-canon-warm-consumer-app-surface, dealt in the bolder re-roll, round 1), seed key 4757b72c. Signature interaction: dragging the violet handle along the timeline moves Live and Logs to that moment, and cards press with a soft spring.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
